# UniServe - 一体化客服系统

## 项目简介

UniServe（Unified Service Platform）是一个现代化的一体化客服工作台系统，为客服坐席提供高效的客户服务管理界面。

## 功能特性

### 🎯 核心功能

- **多会话管理**：支持同时处理多个客户会话，标签页切换
- **实时通信**：实时消息发送接收，客户状态监控
- **排队系统**：可视化展示等待中的客户队列
- **通话集成**：呼出/挂断功能，通话时长记录
- **坐席状态**：在线时长统计，工作状态管理

### 🛠️ 右侧工具栏

1. **通用服务**：快速服务入口、常用模板
2. **保单查询**：客户保单信息查询与展示
3. **实务**：业务流程、常见问题解答
4. **产品**：产品分类、热门产品介绍
5. **留言**：客户留言记录与管理
6. **任务提醒**：待办任务、日程安排

### 💼 管理功能

- **管理员模式**：高级权限管理
- **会话转接**：客户会话转接给其他坐席
- **会话小结**：会话结束后的工作小结
- **快捷回复**：预设常用回复话术

## 技术特点

- 纯HTML + CSS + JavaScript实现，无需后端服务器
- 响应式设计，支持不同屏幕尺寸
- 模块化代码结构，易于维护扩展
- 现代化UI设计，参考Ant Design风格

## 使用说明

### 启动方式

#### macOS / Linux
```bash
# 在项目目录下执行
open index.html
```

#### Windows
```cmd
双击 index.html 文件即可在浏览器中打开
```

```
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏：在线状态 | 坐席信息 | 呼出/挂断 | 管理员模式  │
├──────────┬───────────────────────────┬────────────────────┤
│          │                           │                    │
│  左侧    │       中间对话区          │    右侧工具栏      │
│ 会话列表 │  - 面包屑导航             │  - 通用服务        │
│          │  - 标签页                 │  - 保单查询        │
│ - 排队数 │  - 消息显示区             │  - 实务            │
│ - 会话卡片│  - 输入工具栏             │  - 产品            │
│          │  - 文本输入框             │  - 留言            │
│          │                           │  - 任务提醒        │
```

### 快捷键

- `Ctrl + Enter`：发送消息
- `Tab`：在输入框和按钮间切换
- `Esc`：关闭当前标签页（开发中）
