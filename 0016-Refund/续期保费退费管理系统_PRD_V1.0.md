# 1. 背景与目标

## 1.1 现状问题

原有跨条线业务审批的续期退费业务存在多项不规范问题，业务风险较高：

1. 各分公司续期退费流程、审批标准、申请单证不统一，无全司统一规范
2. 风控规则分散、反洗钱未前置、贷款/佣金/时效管控缺失系统强控
3. 无统一任务查询、统一影像归档、统一审批时效管控机制

## 1.2 建设目标

1. 新建续期保费退费作业功能，实现全司流程统一
2. 下线跨条线业务审批的续期退费功能，所有续期退费统一收口至新建功能
3. 为客户提供95500、柜面两大官方受理渠道
4. 实现规则统一、流程统一、审批统一、影像统一、时效统一
5. 全流程系统刚性风控，前置拦截不合规场景，压降操作风险与合规风险

# 2. 产品概述

## 2.1 产品定位

续期保费退费管理系统是面向保险公司总、分公司各级业务及财务人员、柜面坐席、95500电话坐席、客户等多角色的全流程退费作业平台，实现续期保费退费的统一受理、统一风控、统一审批、统一时效管控。

## 2.2 机构范围

全国38家分公司、2家营运中心全覆盖。

## 2.3 业务范围

寿险续期保费退费业务（含正常续期缴费、垫缴、时效内复效退费场景）。

## 2.4 受理渠道

1. 95500电话客服渠道
2. 线下柜面渠道

## 2.5 终端支持

| 终端类型 | 功能覆盖 |
|----------|----------|
| PC端 | 查询、受理、审批定义、审批、任务管理、统计 |
| 移动端 | 申请、查询、消息通知、审批 |

## 2.6 系统角色

| 角色 | 说明 |
|------|------|
| 续期退费申请人（客户） | 通过移动端提交退费申请 |
| 续期退费受理人 | 95500坐席或柜面人员，受理客户退费申请 |
| 各级业务审批人 | 按金额分层进行业务审批 |
| 各级财务审批人 | 财务复核与审批 |
| 中支/分公司业务内勤 | 任务管理与统计查询 |

# 3. 风控规则

## 3.1 可受理时效规则

系统仅受理以下时效范围内的续期退费（取较晚时间为判断基准）：

1. 保单处于宽限期内缴费
2. 保费实缴完成30日（含）以内

**覆盖场景：**
1. 常规续期缴费退费
2. 垫缴退费
3. 时效内复效退费

**超时效控制：** 超出宽限期且超出实缴30日外，功能直接阻断，不予受理，统一转投诉协调流程处理。

**举例：** T+3天缴费，可以在T+60日内申请退费；如果T+59天缴费，最晚退费申请需在T+89天。

## 3.2 系统强制阻断场景（前置全拦截）

出现以下任一条件，禁止发起退费并弹出标准提示语：

| 序号 | 阻断条件 | 系统提示语 |
|------|----------|-----------|
| 1 | 保单应缴日后发生过理赔、减保业务 | 该单应缴日后发生过理赔业务 或 该单应缴日后发生过减保业务 |
| 2 | 保单已做投保人变更 | 该单已做投保人变更 |
| 3 | 保单存在未结清贷款 | 该单有贷款未还，无法受理，需先做贷款还款 |
| 4 | 反洗钱校验不通过 | 该单不符合反洗钱规则，无法受理，请先进行相关信息的变更 |
| 5 | 非投保人本人申请退费 | 非投保人本人申请，无法受理 |
| 6 | 申请退费入账至非投保人账户 | 退费入账至非投保人账户，无法受理 |
| 7 | 退费方式与原交费方式不一致 | 该单退费方式与原交费方式不一致（现金交费仅可现金退费） |
| 8 | 保费已扣款但系统未完成应用 | 该单已扣款但系统未完成应用，待应用完成后可受理 |
| 9 | 保费已发起退费流程且未撤销、未退费成功、未退费失败 | 该单已发起退费流程，且未撤销、未完成，暂不受理 |

## 3.3 退费账号与支付规则

1. 退费账户必须为投保人本人账户
2. 系统默认优先线上退费；现金、支票退费仅支持柜面办理
3. 账户名称全程不可修改
4. 退万能账户、垫缴退费场景：账号栏置灰、为空、不可编辑
5. 万能账户抵交保费退费，需先补交对应应交保费至公司对公账户后方可受理

# 4. 渠道功能需求

## 4.1 95500电话受理流程

**适用角色：** 95500坐席

**操作流程：**

1. 坐席接到客户电话，从P17查询保单，跳转续期退费受理页面（保单号自动带入且置灰不可修改）
2. 系统自动校验受理规则，不满足直接弹窗提示
3. 页面展示保单信息（隐藏被保险人信息）：保单号、主险名称、缴费账户等
4. 根据客户沟通结果，选择退费期次、录入退费原因
5. 点击"续期退费受理"提交申请
6. 系统生成工单编号，发送至P17任务池
7. 坐席告知客户工单编号及预计处理时效（T+3个工作日内）

## 4.2 柜面受理流程

**适用角色：** 柜面人员

**操作流程：**

1. 柜面人员登录系统，输入保单号查询
2. 系统自动校验受理规则，不满足直接弹窗提示
3. 页面展示保单信息（隐藏被保险人信息）
4. 根据客户沟通结果，选择退费期次、录入退费原因
5. 上传影像资料（退费申请表、证件影像等）
6. 点击"续期退费受理"提交申请
7. 系统生成工单编号，发送至P17任务池
8. 柜面告知客户工单编号及预计处理时效（T+3个工作日内）

## 4.3 客户移动端

**适用角色：** 客户（投保人本人）

**功能列表：**

1. **退费申请：** 输入保单号，系统自动查询并展示保单信息
2. **退费查询：** 查看退费进度（提交→审核中→待财务→已完成）
3. **消息通知：** 审核结果、退费到账等关键节点推送
4. **审批功能：** 接收钉钉审批消息，点击跳转审批页面进行审批

## 4.4 钉钉审批（太好钉+）

**集成方式：** 通过太好钉+推送审批消息，审批人点击消息直接跳转审批页面

**适用角色：** 各级业务审批人、各级财务审批人

---

# 5. 审批流程

## 5.1 审批时效规则

1. 业务审批时效：30分钟内
2. 财务审批时效：50分钟内
3. 超时提醒：业务审批10分钟提醒，20分钟催办
4. 超时默认通过：财务审批超时默认通过

## 5.2 审批权限分层

| 金额范围 | 审批级别 | 业务审批 | 财务审批 |
|----------|----------|----------|----------|
| ≤5000元 | 3级 | 中支业务→分公司业务 | 分公司财务 |
| 5000元-50万元 | 5级 | 中支业务→分公司业务→中支业总→分公司业总→省分业总 | 分公司财务→省分财务 |
| >50万元 | 9级 | 中支业务→分公司业务→中支业总→分公司业总→省分业总→总公司业总+会签 | 分公司财务→省分财务→总公司财务+C+会签 |

## 5.3 审批消息推送

**推送内容：** 工单编号、95500/柜面受理来源、保单号（脱敏）、退费金额、审批链接

# 6. 非功能需求

## 6.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面响应时间 | 普通页面<2秒，复杂查询<5秒 |
| 系统并发用户数 | 支持500+坐席同时在线 |
| 审批消息推送 | 消息延迟<30秒 |

## 6.2 安全需求

1. **身份认证：** 支持工号+密码登录，移动端支持人脸识别
2. **权限控制：** 基于角色的细粒度权限管理
3. **数据脱敏：** 证件号、银行卡号等敏感信息脱敏展示
4. **操作日志：** 关键操作全记录，支持审计追溯

## 6.3 数据需求

1. **工单数据保留：** 至少5年
2. **影像资料：** 对公账户影像、退费申请表影像等
3. **数据备份：** 每日增量备份，每周全量备份
