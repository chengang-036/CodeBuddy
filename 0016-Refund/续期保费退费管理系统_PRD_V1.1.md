# 1. 背景与目标

## 1.1 现状问题

原有跨条线业务审批的续期退费业务存在多项不规范问题，业务风险较高：

1. 各分公司续期退费流程、审批标准、申请单证不统一，无全司统一规范
2. 风控规则分散、反洗钱未前置、贷款/佣金/时效管控缺失系统强控
3. 无统一任务查询、统一影像归档、统一审批时效管控机制

## 1.2 建设目标

1. 新建续期保费退费作业功能，实现全司流程统一
2. 下线跨条线业务审批的续期退费功能，所有续期退费统一收口至新建功能
3. 为客户提供95500、柜面两大官方受理渠道
4. 实现规则统一、流程统一、审批统一、影像统一、时效统一
5. 全流程系统刚性风控，前置拦截不合规场景，压降操作风险与合规风险

# 2. 产品概述

## 2.1 产品定位

续期保费退费管理系统是面向保险公司总、分公司各级业务及财务人员、柜面坐席、95500电话坐席、客户等多角色的全流程退费作业平台，实现续期保费退费的统一受理、统一风控、统一审批、统一时效管控。

## 2.2 机构范围

全国38家分公司、2家营运中心全覆盖。

1. 95500电话客服渠道

# 3. 风控规则

## 3.1 可受理时效规则

系统仅受理以下时效范围内的续期退费（取较晚时间为判断基准）：

1. 保单处于宽限期内缴费
2. 保费实缴完成30日（含）以内

**覆盖场景：**
1. 常规续期缴费退费
2. 垫缴退费
3. 时效内复效退费

**超时效控制：** 超出宽限期且超出实缴30日外，功能直接阻断，不予受理，统一转投诉协调流程处理。

**举例：** T+3天缴费，可以在T+60日内申请退费；如果T+59天缴费，最晚退费申请需在T+89天。

## 3.2 系统强制阻断场景（前置全拦截）

出现以下任一条件，禁止发起退费并弹出标准提示语：

| 序号 | 阻断条件 | 系统提示语 |
|------|----------|-----------|
| 1 | 保单应缴日后发生过理赔、减保业务 | 该单应缴日后发生过理赔业务 或 该单应缴日后发生过减保业务 |
| 2 | 保单已做投保人变更 | 该单已做投保人变更 |
| 3 | 保单存在未结清贷款 | 该单有贷款未还，无法受理，需先做贷款还款 |
| 4 | 反洗钱校验不通过 | 该单不符合反洗钱规则，无法受理，请先进行相关信息的变更 |
| 5 | 非投保人本人申请退费 | 非投保人本人申请，无法受理 |
| 6 | 申请退费入账至非投保人账户 | 退费入账至非投保人账户，无法受理 |
| 7 | 退费方式与原交费方式不一致 | 该单退费方式与原交费方式不一致（现金交费仅可现金退费） |
| 8 | 保费已扣款但系统未完成应用 | 该单已扣款但系统未完成应用，待应用完成后可受理 |
| 9 | 保费已发起退费流程且未撤销、未退费成功、未退费失败 | 该单已发起退费流程，且未撤销、未完成，暂不受理 |

## 3.3 退费账号与支付规则

1. 退费账户必须为投保人本人账户
2. 系统默认优先线上退费；现金、支票退费仅支持柜面办理
3. 账户名称全程不可修改
4. 退万能账户、垫缴退费场景：账号栏置灰、为空、不可编辑
5. 万能账户抵交保费退费，需先补交对应应交保费至公司对公账户后方可受理

# 4. 渠道功能需求

## 4.1 95500电话受理流程

**适用角色：** 95500坐席

### 4.1.1 操作流程

1. 坐席接到客户电话，从P17查询保单号，跳转续期退费受理页面，保单号自动带入且置灰不可修改
2. 系统自动校验受理规则（见3.1、3.2节），不满足直接弹窗提示
3. 页面展示保单信息、缴费信息、续期交费记录（如以下4.1.2节）
4. 根据客户沟通结果，选择退费期次、协助客户录入客户提供的退费原因
5. 点击"提交"按钮，再次校验受理规则，如不满足根据业务规则作系统提示，无法提交
6. 如未选中交费记录，系统提示"未选中交费记录"，无法提交
7. 如可提交，生成续期退费受理业务流水号、保存受理信息（渠道、退费原因、受理人员、受理时间），下发24小时有效的远程申请确认链接、并将远程申请确认链接流水号关联续期退费受理业务流水号，系统提示：提交成功，请通知客户在手机上确认
8. 坐席通知客户，在移动端打开链接，根据保单号、证件号、手机号进行远程续期退费申请确认并补充相关资料

## 4.2 柜面受理流程

**适用角色：** 柜面人员

### 4.2.1 操作流程

1. 柜员录入保单号，查询保单信息，打开并跳转续期退费受理页面，保单号自动带入且置灰不可修改
2. 系统自动校验受理规则（见3.1、3.2节），不满足直接弹窗提示
3. 页面展示保单信息如下（隐藏被保险人信息）
4. 根据客户沟通结果，选择退费期次、协助客户录入客户提供的退费原因
5. 点击"提交"按钮，再次校验受理规则，如不满足根据业务规则作系统提示，无法提交；如未选中交费记录，系统提示"未选中交费记录"，无法提交
6. 如可提交，生成续期退费受理业务流水号、保存受理信息（渠道、退费原因、受理人员、受理时间），下发24小时有效的远程申请确认链接、并将远程申请确认链接流水号关联续期退费受理业务流水号，系统提示：提交成功，请通知客户在手机上确认

8. 柜员可在实际受理过程中，未生成应付记录前，可以：
   - 对已受理信息进行撤回、修改，再次提交
   - 在客户被劝说不再发起退费申请时，对已受理信息进行撤销。撤销时，须录入原因（不低于10个汉字）

## 4.3 续期退费受理业务流水号状态定义

每笔续期退费申请生成唯一的"续期退费受理业务流水号"，贯穿全流程，状态定义如下：

| 序号 | 状态名称 | 状态描述 |
|------|----------|----------|
| 1 | 受理中 | 收到客户续期退费申请，校验受理规则且满足，记录退费申请信息，提交后撤回还未提交 |
| 2 | 已受理待确认 | 收到客户续期退费申请，校验受理规则且满足，记录退费申请信息，已提交，客户远程申请确认还未完成 |
| 3 | 已完成远程申请确认 | 客户已完成远程申请确认，包括补充填写申请原因、上传资料，待进入审批环节 |
| 4 | 审批还未完成 | 进入审批环节，还未审批通过 |
| 5 | 审批完成 | 完成审批，进入核心、代收付等退费操作 |
| 6 | 退费完成 | 完成退费 |
| 7 | 退费失败 | 核心、代收付退费过程中有问题，退费失败 |

**状态流转图：**

```
受理中 → 已受理待确认 → 已完成远程申请确认 → 审批还未完成 → 审批完成 → 退费完成
                    ↑                                                      ↓
                    └──────────────────────────────────────────────────→ 退费失败
```

# 5. 审批流程

## 5.1 审批时效规则

1. 业务审批时效：30分钟内
2. 财务审批时效：50分钟内
3. 超时提醒：业务审批10分钟提醒，20分钟催办
4. 超时默认通过：财务审批超时默认通过

## 5.2 审批权限分层

| 金额范围 | 审批级别 | 业务审批 | 财务审批 |
|----------|----------|----------|----------|
| ≤5000元 | 3级 | 中支业务→分公司业务 | 分公司财务 |
| 5000元-50万元 | 5级 | 中支业务→分公司业务→中支业总→分公司业总→省分业总 | 分公司财务→省分财务 |
| >50万元 | 9级 | 中支业务→分公司业务→中支业总→分公司业总→省分业总→总公司业总+会签 | 分公司财务→省分财务→总公司财务+C+会签 |

## 5.3 审批消息推送

**推送内容：** 工单编号、95500/柜面受理来源、保单号（脱敏）、退费金额、审批链接

1. **身份认证：** 支持工号+密码登录，移动端支持人脸识别
2. **权限控制：** 基于角色的细粒度权限管理
3. **数据脱敏：** 证件号、银行卡号等敏感信息脱敏展示
4. **操作日志：** 关键操作全记录，支持审计追溯

## 6.3 数据需求

1. **工单数据保留：** 至少5年
2. **影像资料：** 对公账户影像、退费申请表影像等
3. **数据备份：** 每日增量备份，每周全量备份
