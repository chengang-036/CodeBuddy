岗位薪酬分摊计算工具 - Windows使用说明
=========================================

一、系统要求
-----------
- Windows 7/8/10/11
- 浏览器：Edge、Chrome、Firefox（推荐使用Edge或Chrome）
- 需要网络连接（仅首次使用时加载Excel处理库）

二、使用步骤
-----------
1. 双击打开 index.html 文件
   - Windows会自动使用默认浏览器打开
   - 推荐使用Edge或Chrome浏览器

2. 上传Excel文件
   - 点击上传区域，或直接拖拽文件到页面
   - 支持 .xlsx 格式文件

3. 系统自动验证文件
   - 检查是否包含必需的3个Sheet（名称为 1、2、3）
   - 验证通过后显示"开始计算"按钮

4. 点击"开始计算"按钮
   - 系统自动执行5步计算流程
   - 显示实时进度

5. 点击"下载结果"按钮
   - 文件自动保存到"下载"文件夹
   - 文件名格式：原文件名_计算结果.xlsx

三、Excel文件格式要求
-------------------
您的Excel文件必须包含以下3个Sheet（名称必须是 1、2、3）：

【Sheet 1】分公司岗位分类/人力/薪酬
  列A：岗位分类名称
  列B：人力数量
  列C：薪酬

【Sheet 2】分公司岗位分类/服务精力占比
  列A：岗位分类名称
  列B：服务精力占比（小数，如0.3表示30%）

【Sheet 3】分摊结果
  必须包含的列：
    - 岗位属性
    - 岗位分类
    - 人力
    - 薪酬
    - 分摊1
    - 分摊2

四、计算说明
-----------
系统会自动完成以下计算：

步骤1：数据填充
  - 从Sheet1读取人力和薪酬数据
  - 根据岗位分类填充到Sheet3

步骤2：计算人力费用占比（分摊1）
  - 计算每行薪酬占总薪酬的百分比
  - 人力或薪酬为空的行不参与计算

步骤3：分摊管理成本（分摊2）
  - 计算所有管理岗的人力费用占比总和
  - 按非管理岗的人力占比分摊管理岗成本
  - 管理岗的分摊2列会被清空

步骤4：分摊服务成本（分摊3）
  - 计算所有服务岗的分摊管理成本总和
  - 根据Sheet2的服务精力占比分摊到其他岗位
  - 服务岗的分摊3列会被清空

步骤5：生成结果
  - 自动添加"分摊3"列
  - 重命名列标题
  - 添加合计行

五、常见问题（Windows专用）
------------------------
Q1: 双击文件后没有反应？
A1: 右键点击 index.html → 打开方式 → 选择浏览器（Edge或Chrome）

Q2: 提示"Excel处理库加载失败"？
A2: 解决方法：
    - 检查网络连接是否正常
    - 刷新页面（按F5键）
    - 尝试更换浏览器
    - 关闭防火墙或杀毒软件后重试

Q3: 页面显示乱码？
A3: 右键点击 index.html → 属性 → 确认文件编码为UTF-8

Q4: 无法上传文件？
A4: - 确认文件格式为 .xlsx（不是 .xls）
    - 确认文件未被其他程序占用（关闭Excel）
    - 文件路径不要包含中文特殊字符

Q5: 下载的文件在哪里？
A5: 默认保存在Windows的"下载"文件夹：
    C:\Users\您的用户名\Downloads\

Q6: 计算很慢或卡住？
A6: - 如果数据量很大，请耐心等待
    - 不要关闭浏览器窗口
    - 按F12打开开发者工具，查看Console（控制台）是否有错误信息

Q7: Edge浏览器提示安全警告？
A7: 这是正常的本地文件提示，点击"允许"或"运行"即可

六、浏览器推荐设置
---------------
【Microsoft Edge】（推荐）
- Windows 10/11自带，无需安装
- 兼容性最好
- 打开方式：右键 index.html → 打开方式 → Microsoft Edge

【Google Chrome】
- 需要单独下载安装
- 性能优秀
- 下载地址：https://www.google.com/chrome/

七、调试方法
-----------
如果遇到问题，按F12打开开发者工具查看详细日志：

1. 打开 index.html
2. 按F12键（或右键→检查）
3. 切换到"Console"（控制台）标签
4. 上传文件并执行计算
5. 查看输出的调试信息：
   - 管理岗统计
   - 人力占比计算
   - 分摊过程
   - 最终结果

十、注意事项
-----------
1. 首次使用需要联网加载Excel处理库（约500KB）
2. 加载成功后，关闭网络也能继续使用
3. 建议使用前备份原始Excel文件
4. 确保Excel文件格式完全符合要求
5. 岗位分类名称必须严格匹配（包括括号、空格）
6. 不要在计算过程中关闭浏览器
