# 岗位薪酬分摊计算工具

## 功能说明

这是一个用于自动计算岗位薪酬分摊的Web应用，支持Excel文件上传和自动化数据处理。

## 使用方法

1. 打开 `index.html` 文件
2. 上传包含3个Sheet的Excel文件（.xlsx格式）
3. 系统自动验证文件结构
4. 点击"开始计算"按钮执行分摊计算
5. 计算完成后下载结果文件

## Excel文件要求

### Sheet1：分公司岗位分类/人力/薪酬
- 列A：岗位分类名称
- 列B：人力数量
- 列C：薪酬

### Sheet2：分公司岗位分类/服务精力占比
- 列A：岗位分类名称
- 列B：服务精力占比（小数形式，如0.3表示30%）

### Sheet3：分摊结果
- 列：岗位属性、岗位分类、人力、薪酬、计算后的分摊1、计算后的分摊2
- 系统会自动添加"计算后的分摊3"列

## 计算逻辑

### 步骤1：数据填充
将Sheet1中的人力数量、薪酬按照岗位分类对应关系填入Sheet3的人力、薪酬列。

### 步骤2：计算分摊1（薪酬占比）
根据Sheet3中的薪酬，在分摊1列中填写每行薪酬占总薪酬的百分比（空薪酬不参与计算）。

公式：`分摊1 = 薪酬 / 总薪酬`

### 步骤3：管理岗分摊（分摊2）
1. 筛选出所有"管理岗"
2. 计算以下岗位的总人力：
   - 服务岗
   - 专业岗（不分渠道）
   - 专业岗（个人渠道）
   - 专业岗（团险渠道）
   - 专业岗（银保渠道）
3. 将管理岗的分摊1按照各岗位人力占比分摊到上述岗位
4. 结果存入分摊2列

公式：`分摊2 = 分摊1 + (管理岗总分摊 × 该岗位人力 / 目标岗位总人力)`

### 步骤4：服务岗分摊（分摊3）
1. 筛选出所有"服务岗"
2. 根据Sheet2中的服务精力占比，将服务岗的分摊2按比例分摊到专业岗
3. 目标岗位：
   - 专业岗（不分渠道）
   - 专业岗（个人渠道）
   - 专业岗（团险渠道）
   - 专业岗（银保渠道）
4. 结果存入分摊3列

公式：`分摊3 = 分摊2 + (服务岗总分摊 × Sheet2中对应岗位的服务精力占比)`

## 注意事项

1. 确保Excel文件包含名为"1"、"2"、"3"的Sheet
2. Sheet3必须包含"岗位属性"、"岗位分类"、"人力"、"薪酬"等列
3. 岗位分类名称必须完全匹配（区分大小写）
4. 薪酬和人力必须是数字格式
5. 服务精力占比应为小数（0-1之间）
