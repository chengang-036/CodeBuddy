# 高中数学数字化错题本管理工具

这是一个为高中生专门设计的数字化错题管理方案，旨在通过高效的整理与分析，帮助学生查漏补缺，提升数学成绩。

## 🌟 核心功能

1. **多维录入**：支持录入章节知识点、难度等级、掌握程度、错误原因、正确解题思路等。
2. **图片支持**：支持点击上传题目图片或**直接从剪贴板粘贴图片**（截屏后直接Ctrl+V），极大提高整理效率。
3. **数字化存储**：所有数据保存在本地 Excel 文件中，方便备份、打印和分享。
4. **智能统计**：实时统计累计错题数、已掌握数、薄弱知识点分布。
5. **离线运行**：单 HTML 文件设计，无需网络环境即可稳定使用。

## 🚀 快速上手

1. **打开应用**：双击 `index.html` 即可在浏览器中运行。
2. **初始化**：
   - 如果是第一次使用，点击 **“✨ 创建新错题本”**。
   - 如果已有错题文件，直接将 Excel 文件拖入上传区域。
3. **录入错题**：
   - 填写相关字段。
   - 使用截图工具截取题目，直接在页面中粘贴，或点击图片区域上传。
   - 点击 **“➕ 保存错题”**。
4. **管理与复习**：
   - 下方列表会实时显示已录入的题目。
   - 定期查看“薄弱章节”统计，进行针对性训练。
5. **导出备份**：
   - 点击 **“💾 导出并下载Excel”** 保存当前所有记录。

## 💡 建议方案

- **分类整理**：建议按照数学章节（函数、导数、三角函数、立体几何等）进行精确贴标签。
- **定期清理**：对于已经完全掌握（连续三次做对）的题目，可以将掌握程度改为“已掌握”。
- **打印复习**：可以将生成的 Excel 文件打印出来，重新遮住答案进行二次练习。

## 🛠️ 技术说明

- **技术栈**：HTML5, CSS3, Vanilla JS, XLSX.js
- **存储机制**：浏览器内存运行 + Excel 本地持久化
- **兼容性**：支持主流现代浏览器（Chrome, Edge, Firefox, Safari）
