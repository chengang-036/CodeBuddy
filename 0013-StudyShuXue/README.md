# 高中数学数字化错题本管理工具

这是一个为高中生专门设计的数字化错题管理方案，旨在通过高效的整理与分析，帮助学生查漏补缺，提升数学成绩。

## 🌟 核心功能

1. **多维录入**：支持录入章节知识点、难度等级、掌握程度、错误原因、正确解题思路等。
2. **图片支持**：支持点击上传题目图片或**直接从剪贴板粘贴图片**（截屏后直接Ctrl+V），最多支持10张图片。
3. **数学公式**：支持LaTeX数学公式输入，使用 `$公式$` 表示行内公式，`$$公式$$` 表示独立公式。
4. **学习方法论**：支持添加学习方法、解题技巧、知识点总结等，内容支持Markdown格式和数学公式。
5. **数字化存储**：使用IndexedDB本地存储，支持导出Excel（含方法论工作表）和完整ZIP包。
6. **导入导出**：支持导出完整ZIP包，也支持导入ZIP包（追加模式）。
7. **智能统计**：实时统计累计错题数、已掌握数、薄弱知识点分布。
8. **离线运行**：单 HTML 文件设计，无需网络环境即可稳定使用。

## 📐 数学公式示例

在题目描述、错误原因、正确解题思路、**学习方法论**中，你可以使用LaTeX语法输入数学公式：

- 行内公式：`$x^2 + y^2 = r^2$` 显示为：$x^2 + y^2 = r^2$
- 独立公式：`$$\int_0^1 f(x)dx$$` 显示为居中的积分公式
- 分数：`$\frac{a}{b}$` 显示为：$\frac{a}{b}$
- 根式：`$\sqrt{x}$` 或 `$\sqrt[3]{x}$`
- 上下标：`$x^2$`, `$x_i$`, `$x_i^2$`
- 求和：`$\sum_{i=1}^n i$` 显示为：$\sum_{i=1}^n i$
- 极限：`$\lim_{x\to 0} \frac{\sin x}{x}$`
- 导数：`$\frac{dy}{dx}$` 或 `$f'(x)$`

## 📝 Markdown格式支持

在**学习方法论**中，支持完整的Markdown语法：

- **标题**：`# 一级标题`、`## 二级标题`、`### 三级标题`
- **强调**：`**粗体**`、`*斜体*`
- **列表**：
  - 无序列表：`- 项目1`
  - 有序列表：`1. 项目1`
- **代码**：`` `行内代码` `` 或使用三个反引号包裹代码块
- **引用**：`> 引用内容`
- **表格**：支持Markdown表格语法
- **链接**：`[文字](URL)`

## 🚀 快速上手

1. **打开应用**：双击 `index.html` 即可在浏览器中运行。
2. **初始化**：
   - 如果是第一次使用，点击 **"✨ 创建新错题本"**。
   - 如果有备份的ZIP文件，点击顶部的 **"📦 导入ZIP"** 导入数据。
3. **管理学习方法论**：
   - 点击顶部 **"📖 学习方法论"** 按钮。
   - 添加学习方法、解题技巧、知识点总结等（支持Markdown和数学公式）。
   - 例如：二次函数解题步骤、三角函数公式归纳、立体几何做题技巧等。
4. **录入错题**：
   - 填写相关字段（支持数学公式输入）。
   - 使用截图工具截取题目，直接在页面中粘贴（Ctrl+V），或点击图片区域上传。
   - 点击 **"➕ 保存错题"**。
5. **管理与复习**：
   - 下方列表会实时显示已录入的题目。
   - 点击题目卡片查看详情，可以编辑或删除。
   - 定期查看"薄弱章节"统计，进行针对性训练。
6. **导出备份**：
   - 点击 **"💾 导出Excel"** 导出错题记录和学习方法论（两个工作表）。
   - 点击 **"📦 导出完整包"** 保存所有记录、方法论和图片到ZIP文件。
   - 建议定期备份到iCloud云盘。

## 💡 建议方案

- **分类整理**：建议按照数学章节（函数、导数、三角函数、立体几何等）进行精确贴标签。
- **方法论积累**：将重要的解题技巧、公式推导、易错点总结到学习方法论中，方便随时查阅。
- **定期清理**：对于已经完全掌握（连续三次做对）的题目，可以将掌握程度改为"已掌握"。
- **打印复习**：可以将生成的 Excel 文件打印出来，重新遮住答案进行二次练习。

## 🛠️ 技术说明

- **技术栈**：HTML5, CSS3, Vanilla JS, XLSX.js, JSZip, MathJax, Marked.js
- **存储机制**：IndexedDB本地存储 + ZIP文件导出
- **数学渲染**：MathJax 3.x（支持LaTeX语法）
- **Markdown渲染**：Marked.js 11.x（支持完整Markdown语法）
- **图片处理**：Canvas压缩（最大800px，质量70%）
- **兼容性**：支持主流现代浏览器（Chrome, Edge, Firefox, Safari）
