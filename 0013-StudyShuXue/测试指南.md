# 快速测试 AI解答功能

## 🧪 测试步骤

### 1. 打开应用
在浏览器中打开 `index.html`

### 2. 新增错题
点击顶部"新增错题"按钮

### 3. 输入测试题目
在"题目描述"文本框中输入一道数学题，例如：

```
已知函数 f(x) = x^2 - 4x + 3，求：
(1) 函数的对称轴
(2) 函数的最小值
(3) 函数与x轴的交点
```

### 4. 点击AI解答按钮
点击"正确解题思路"文本框下方的"🤖 AI解答本题"按钮

### 5. 等待生成
等待5-15秒，AI会自动生成解答

### 6. 查看结果
解答会自动填入"正确解题思路"文本框，包含：
- 📖 解题思路
- 📝 详细步骤
- ✅ 最终答案
- 💡 知识点总结

## 🎯 测试案例

### 案例1：二次函数
```
求二次函数 y = 2x^2 - 4x + 1 的顶点坐标和对称轴
```

### 案例2：三角函数
```
已知 sin(α) = 3/5，且 α 在第一象限，求 cos(α) 和 tan(α)
```

### 案例3：导数问题
```
求函数 f(x) = x^3 - 3x^2 + 2 在 x=2 处的切线方程
```

### 案例4：立体几何
```
已知正方体 ABCD-A'B'C'D' 的棱长为 2，求体对角线 AC' 的长度
```

## ✅ 预期结果

AI应该生成格式规范的解答，包括：

1. **解题思路**：用通俗语言分析题目
2. **详细步骤**：逐步展示计算过程
3. **最终答案**：给出明确结果
4. **知识点总结**：归纳涉及的知识点

## ⚠️ 注意事项

- 确保已配置豆包API（apiKey和endpointId）
- 确保网络连接正常
- 题目描述越清晰，解答质量越好

## 🐛 如果遇到问题

### 提示"请先配置豆包API"
在 `index.html` 中找到 `DOUBAO_CONFIG`，填入你的配置：
```javascript
const DOUBAO_CONFIG = {
    endpoint: 'https://ark.cn-beijing.volces.com/api/v3/chat/completions',
    apiKey: '你的API Key',
    endpointId: 'ep-xxxxx',
    model: 'ep-xxxxx'
};
```

### 提示"AI未能生成解答"
- 检查题目描述是否完整
- 尝试简化题目表述
- 检查浏览器控制台的错误信息

### 按钮点击无反应
- 按 F12 打开浏览器控制台
- 查看是否有 JavaScript 错误
- 检查题目描述框是否为空
