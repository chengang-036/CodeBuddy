# Clothes - Windows本地衣橱管理系统

一个完全本地化运行的衣橱管理系统，专为Windows用户优化。

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）
直接双击 `启动应用.bat` 文件，系统会自动：
1. 检测并使用最佳浏览器（Chrome、Edge 或默认浏览器）
2. 打开应用主页
3. 无需任何配置

### 方法二：手动打开
直接双击 `index.html` 文件，使用默认浏览器打开

## ✨ 核心特性

### 🎯 Windows优化版特性
- **更激进的压缩**：图片自动压缩至600px宽度（比Mac版小），质量60%
- **节省空间**：可存储约 **20-40** 张照片（取决于原始大小）
- **完全离线**：无需联网，数据不会上传
- **即开即用**：无需安装，双击即可运行
- **字体优化**：使用Microsoft YaHei，更适合Windows显示

### 📁 功能模块

#### 1. 衣服上架 (`upload.html`)
- 📤 上传衣服照片（支持拖拽）
- ✍️ 添加描述和标签
- 🗜️ 自动压缩图片（600px宽度，60%质量）
- 📊 实时显示压缩效果

#### 2. 衣橱管理 (`wardrobe.html`)
- 👗 查看所有衣服

#### 3. 搭配衣服 (`match.html`)
- 👕 选择上装
- 👖 选择下装
- 👞 选择鞋子/配饰
- 🔖 按标签快速筛选
- 💾 保存搭配方案

#### 4. 搭配方案 (`outfits.html`)
- 💼 查看所有搭配
- 🔍 搜索搭配名称

## 📊 存储说明

### 存储限制
- **localStorage容量**：通常5-10MB
- **Windows优化**：通过更激进的压缩，可存储更多衣服
- **典型压缩效果**：原始3MB照片 → 约150-300KB

### 存储管理
1. 打开浏览器开发者工具（按 `F12`）
2. 查看控制台（Console）可以看到：
   - 每次上传的压缩信息
   - 当前存储使用情况
3. 当存储超过4MB时会收到警告

### 如果存储空间满了
1. 在衣橱管理中删除不需要的衣服
2. 或清空所有数据重新开始：
   - 按 `F12` 打开开发者工具
   - 切换到 Console（控制台）
   - 输入：`localStorage.clear()` 然后按回车
   - 刷新页面（`Ctrl+R`）

## 💡 使用技巧

### 上传照片
1. **建议**：上传前适当裁剪照片，避免超大尺寸
2. **支持格式**：JPG、PNG
3. **拖拽上传**：可直接拖拽图片到上传区域
4. **推荐尺寸**：800-1200px宽度的照片

### 标签使用
- 使用标签快速分类（如：夏季、冬季、正式、休闲）
- 可以按标签搜索和筛选
- 标签可以随时编辑

### 搭配技巧
- 先按标签筛选，缩小选择范围
- 使用搜索功能快速定位
- 给搭配起个有意义的名字（如：约会装、上班装）

## 🔧 故障排除

### 图片不显示
1. 检查浏览器是否支持localStorage
2. 清除浏览器缓存后重试
3. 尝试使用其他浏览器

### 保存失败
1. 检查是否存储空间已满
2. 查看浏览器控制台的错误信息
3. 尝试删除一些旧数据

### 数据丢失
- localStorage数据存储在浏览器中
- 清除浏览器数据会导致数据丢失
- 建议定期截图保存重要搭配

## 🆚 与Mac版本的差异

### Windows版优化
1. **图片压缩**：600px vs 800px（Mac版）
2. **压缩质量**：60% vs 70%（Mac版）
3. **字体**：Microsoft YaHei vs -apple-system
4. **启动方式**：提供.bat启动脚本
5. **浏览器兼容**：优先适配Chrome和Edge

### 压缩效果对比
- **Mac版**：800px, 70%质量，约200-500KB/张
- **Windows版**：600px, 60%质量，约150-300KB/张
- **存储能力**：Windows版可多存储约20-30%的照片

## ⚠️ 重要提示

1. **数据安全**：
   - 数据存储在浏览器本地
   - 清除浏览器数据会导致数据丢失
   - 建议定期备份重要信息

2. **隐私保护**：
   - 所有数据仅存储在本地
   - 不会上传到任何服务器
   - 完全离线运行

3. **浏览器限制**：
   - 不同浏览器的localStorage容量可能不同
   - 建议在同一浏览器中使用

## 📞 常见问题

**Q: 为什么要压缩图片？**  
A: 浏览器localStorage空间有限（5-10MB），压缩可以存储更多照片。

**Q: 压缩会影响图片质量吗？**  
A: 会有一定影响，但在正常查看时几乎看不出差异。

**Q: 可以导出数据吗？**  
A: 目前版本不支持导出，数据仅存储在浏览器中。

**Q: 可以在多台电脑上使用吗？**  
A: 可以复制整个文件夹到其他电脑，但数据不会同步（各自独立）。

**Q: 启动脚本打不开怎么办？**  
A: 直接双击 `index.html` 使用默认浏览器打开即可。
