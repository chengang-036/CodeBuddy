====================================
    数据脱敏工具 - Windows 使用说明
====================================

【重要】首次使用必读：

1️⃣ 必须联网
   - 工具需要从网络加载Excel处理库
   - 确保电脑已连接互联网
   - 加载成功后可以离线使用

2️⃣ 使用步骤

   步骤1：打开文件
   --------
   方式A：直接双击 desensitize.html
   方式B：右键 → 打开方式 → Microsoft Edge
   
   步骤2：等待加载
   --------
   - 首次打开需要等待5-10秒
   - 看到完整界面说明加载成功
   - 如果显示"加载失败"，点击刷新按钮
   
   步骤3：上传文件
   --------
   - 点击上传区域
   - 选择您的Excel文件（.xlsx 或 .xls）
   - 或直接拖拽文件到页面
   
   步骤4：等待处理
   --------
   - 进度条显示处理进度
   - 查看日志了解详细过程
   
   步骤5：下载结果
   --------
   - 点击"下载脱敏后的文件"按钮
   - 文件会自动添加"_脱敏"后缀


3️⃣ 常见问题解决

   问题1：显示"XLSX is not defined"错误
   ----------------------------------------
   原因：Excel处理库未加载成功
   解决：
   ✓ 检查电脑是否联网
   ✓ 按 Ctrl+F5 强制刷新页面
   ✓ 关闭杀毒软件/防火墙后重试
   ✓ 换一个浏览器试试（Chrome/Firefox）

   问题2：页面显示不完整
   ----------------------
   解决：
   ✓ 等待10秒后再操作
   ✓ 刷新页面（F5）
   ✓ 检查网络连接

   问题3：无法选择文件
   -------------------
   解决：
   ✓ 确认文件格式是 .xlsx 或 .xls
   ✓ 文件没有被Excel占用（关闭Excel）
   ✓ 文件没有损坏

   问题4：下载的文件打不开
   ------------------------
   解决：
   ✓ 用Excel/WPS打开（不要用记事本）
   ✓ 检查原文件是否正常
   ✓ 重新处理一次


4️⃣ 脱敏结果示例

   手机号：
   13812345678  →  138******78-HX-456789
   13812345778  →  138******78-HX-923456
   13812345678  →  138******78-HX-456789  ✓ 相同号码

   座机号：
   010-12345678  →  010-****78-HX-234567

   身份证：
   110101199001011234  →  110101********1234


5️⃣ 处理的列

   B列（第2列） - 手机号/座机号
   Q列（第17列）- 混合内容（自动识别）
   W列（第23列）- 身份证


6️⃣ 安全提示

   ✓ 所有处理都在本地完成
   ✓ 数据不会上传到任何服务器
   ✓ 请保留原文件备份
   ✓ 脱敏后无法还原


7️⃣ 技术支持

   如果遇到其他问题：
   1. 按 F12 打开开发者工具
   2. 点击 Console 标签
   3. 查看红色错误信息
   4. 截图发送给技术人员
