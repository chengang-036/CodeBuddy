# 数据脱敏工具

## 功能说明

这是一个专门用于WPS/Excel表格敏感信息脱敏的工具，可以安全地处理手机号、座机号和身份证等敏感数据。

## 使用方法

### 方式一：直接使用（推荐）
1. 双击打开 `desensitize.html` 文件
2. 点击上传区域或拖拽Excel文件到页面
3. 等待处理完成
4. 点击下载按钮获取脱敏后的文件

### 方式二：浏览器打开
1. 在浏览器中打开 `desensitize.html`
2. 按照页面提示操作

## 脱敏规则

### 核心原理

**手机号/座机号**：使用星号脱敏 + 哈希值标识
- 中间用星号隐藏
- 末尾追加 `-HX-哈希值` 作为唯一标识
- 相同号码有相同哈希值，不同号码有不同哈希值

**身份证**：直接星号脱敏
- 不添加哈希值
- 简单直接，保留前后信息

### 1. 第二列（B列）- 电话号码

**手机号（11位）**：
- 格式：`前3位******后2位-HX-哈希值`
- 示例：
  - `13812345678` → `138******78-HX-456789`
  - `13812345778` → `138******78-HX-923456`
  - `13812345678`（再次出现）→ `138******78-HX-456789` ✅ 哈希值相同

**座机号**：
- 格式：`区号-****后2位-HX-哈希值`
- 示例：
  - `010-12345678` → `010-****78-HX-234567`
  - `021-87654321` → `021-****21-HX-567890`

### 2. Q列 - 混合内容

自动识别并脱敏其中的：
- **手机号**：规则同B列（带 `-HX-` 哈希值）
- **座机号**：规则同B列（带 `-HX-` 哈希值）
- **身份证**：规则同W列（不带哈希值）

### 3. W列 - 身份证

**18位身份证**：
- 格式：`前6位********后4位`
- 示例：`110101199001011234` → `110101********1234`

**15位身份证**：
- 格式：`前6位*****后4位`
- 示例：`110101900101123` → `110101*****0123`

## 核心特点

✅ **手机号唯一标识**：通过 `-HX-哈希值` 区分不同号码  
✅ **身份证简洁**：直接星号脱敏，清晰易读  
✅ **一致性保证**：相同号码的哈希值相同  
✅ **完全本地**：数据不上传，100%安全  
✅ **原文件保护**：生成新文件，原文件不受影响  

## 技术说明

- 使用 SheetJS (XLSX) 库处理Excel文件
- 纯前端实现，数据安全可靠
- 支持 .xlsx 和 .xls 格式
- 脱敏映射表确保相同数据脱敏结果一致

## 注意事项

1. 支持的文件格式：`.xlsx`、`.xls`
2. 第二列指的是B列（Excel的第二列）
3. Q列指的是第17列
4. W列指的是第23列
5. 处理大文件时可能需要稍等片刻
6. 下载的文件名会自动添加"_脱敏"后缀

## 示例

### 原数据
```
B列: 13812345678, 13812345778, 13812345678
Q列: 联系方式：13987654321，身份证：110101199001011234
W列: 320102198801012345
```

### 脱敏后
```
B列: 
  138******78-HX-456789
  138******78-HX-923456  ← 虽然前后一样，但哈希值不同
  138******78-HX-456789  ← 哈希值与第1个相同 ✅

Q列: 
  联系方式：139******21-HX-123456，身份证：110101********1234

W列: 
  320102********2345
```

### 如何判断是否同一号码？

**方法**：看 `-HX-` 后面的哈希值
- `138******78-HX-456789` 和 `138******78-HX-456789` → 哈希值相同 = 同一号码 ✅
- `138******78-HX-456789` 和 `138******78-HX-923456` → 哈希值不同 = 不同号码 ✅

## 常见问题

**Q: 为什么手机号后面有 `-HX-` 和数字？**  
A: `-HX-` 后面是哈希值，用于区分不同号码。相同号码的哈希值相同，不同号码的哈希值不同。

**Q: `138******78` 看起来一样，怎么区分？**  
A: 看 `-HX-` 后的哈希值。例如：
   - `138******78-HX-456789` 
   - `138******78-HX-923456`
   - 哈希值不同，说明是两个不同的号码。

**Q: 身份证为什么没有哈希值？**  
A: 按照您的要求，身份证直接用星号脱敏，不添加哈希值，保持简洁。

**Q: 数据会上传吗？**  
A: 不会，所有处理都在本地浏览器完成，100%安全。

**Q: 可以还原吗？**  
A: 不可以，这是单向脱敏，无法还原。请保留原文件备份。
