# 坦克大战 1990 经典复刻（Tank Battle 1990）

参照 FC《坦克大战 1990》经典版的单机复刻，一份源码两个出口：

- `preview/` — 网页预览版（纯静态、零依赖），Mac 浏览器打开即玩
- `minigame/` — 微信小游戏工程（用微信开发者工具导入即可运行）

## 玩法
- 每关 20 辆敌方坦克（普通/快速/火力/装甲 4 类），同屏最多 4 辆；清完进下一关，共 10 关。
- 守住底部老鹰基地：基地被毁或生命耗尽即失败。
- 地形：砖（可打穿）、钢（3 级炮可破）、水（挡车不挡弹）、冰（打滑）、草（遮挡）。
- 道具（击毁红闪敌人掉落）：星（升级，2 级双发 3 级破钢）、头盔（无敌）、坦克（加命）、炸弹（清场）、铁锹（基地钢化）、时钟（冻结）。

## 操作
| 平台 | 移动 | 射击 | 暂停 |
|------|------|------|------|
| Mac 网页 | 方向键 / WASD | 空格 / J | P / ESC |
| 手机网页 | 左下虚拟摇杆（按住拖动） | 右下开火钮（按住连发） | 顶栏按钮 |
| 微信小游戏 | 左半屏按住拖动（浮动摇杆） | 右半屏按住连发 | 点按（暂停中恢复） |

手机摇杆说明：摇杆是**浮动原点**——手指按在哪里，哪里就是圆心，不要求按准摇杆中心；
拖动超过 14px 死区后按主导轴判定四方向，松手立刻停止。摇杆帽的可动半径做了限位，
不会推出底盘。

## 像素素材
坦克按 **32×32 原生绘制**（1 像素 = 1 画布像素，与场景砖块同密度），
结构分为履带 / 车体 / 炮塔 / 炮管四层，四方向由同一朝上底图旋转 90° 生成。
`tools/sprites.html` 可以把所有坦克放大 10 倍逐个检查。

## 目录结构
```
tank1990/
├── preview/          # 网页预览（index.html + js/ + css/ + assets/svg 素材）
│   └── js/           # 全部游戏源码（单一源码）
├── minigame/         # 微信小游戏工程（game.js 入口 + js/ 为源码副本）
├── docs/             # 需求分析与任务拆解
└── tools/            # smoke.js 冒烟测试 / shot.html 渲染自检 / build_minigame.sh
```

## 本地运行 / 测试
```bash
# 网页版：任意静态服务器指向 preview/
python3 -m http.server 8765   # 打开 http://localhost:8765/preview/

# 测试（全部为 headless，无需浏览器）
node tools/smoke.js           # 冒烟测试：关卡/战斗/道具/状态机/通关
node tools/test-hold-fire.js  # 按住连发
node tools/test-stick.js      # 手机摇杆方向逻辑（互斥、换向不残留、死区）

# 同步源码到小游戏工程
./tools/build_minigame.sh
```

## 微信小游戏发布
1. `tools/build_minigame.sh` 同步源码；
2. 微信开发者工具导入 `minigame/`，把 `project.config.json` 中的 `appid` 换成自己的小游戏 AppID；
3. 本工程为纯单机玩法，未使用登录/支付/排行榜等需要额外资质的接口。
