# 坦克大战 1990 经典复刻 — 需求分析与任务拆解

## 一、需求分析

### 1. 原始需求
> 参照坦克大战 1990 经典版（单机版），做一个微信小游戏，能够在 Mac 网页端玩起来。

### 2. 需求清单（含验收标准）

| # | 需求项 | 说明 | 验收标准 |
|---|--------|------|----------|
| R1 | 经典玩法还原 | 13x13 砖块战场（26x26 小格）、坦克 4 向移动、射击、守基地 | 移动/射击手感接近 FC 原作，换向自动对齐网格可穿通道 |
| R2 | 地形系统 | 砖（可破坏）、钢（3 级炮可破）、水（阻挡坦克不挡子弹）、冰（打滑）、草（遮挡视线） | 每种地形行为符合经典规则 |
| R3 | 敌方系统 | 4 类敌人（普通/快速/火力/装甲4血）、每关 20 辆、同屏 4 辆、3 生成点 | AI 巡逻+索敌，装甲车掉血变色 |
| R4 | 道具系统 | 星/头盔/加命/炸弹/铁锹/时钟 6 种，携带道具的敌人红闪 | 拾取生效、限时闪烁、效果正确 |
| R5 | 关卡系统 | 10 关手工关卡 + 敌人构成随关卡通进，通关判定 | 清完 20 辆进结算并进入下一关 |
| R6 | 计分与持久化 | 击毁计分 100/200/300/400，道具 500 分，本地最高分 | 刷新后最高分保留 |
| R7 | 完整界面流 | 标题→关卡过场→战斗→暂停→结算→Game Over→通关 | 状态流转正确，可反复开始 |
| R8 | Mac 网页端可玩 | 纯静态零依赖，键盘操作 | 浏览器打开即玩，方向键/WASD+空格 |
| R9 | 移动端适配 | 虚拟十字键+开火钮（热区≥88px）、安全区、DPR、音频手势解锁 | 手机打开可正常操作 |
| R10 | 微信小游戏工程 | 单一源码双出口，wx.* 按官方文档使用 | 导入微信开发者工具即可运行 |

### 3. 明确不做（合规边界）
- 不做抽奖、付费、排行榜联网等需要资质/后端的玩法；
- 不采集任何用户数据，仅本地存储最高分。

## 三、技术方案
- **引擎**：原生 Canvas 2D + 纯 JS（无引擎依赖，包体 <100KB），网页端与微信小游戏共用同一份 `preview/js` 源码。
- **尺寸契约**：逻辑画布 512x480；战场 416x416（26x26 小格 x 16px）；坦克 32x32；砖块 32x32（2x2 小格，最小破坏单位 16x16）。
- **素材**：全部运行时像素矩阵生成（网页/小游戏一致、无加载等待）；外层 UI 用 SVG（`模块_元素_状态.svg` 命名）。
- **性能**：静态地形层缓存（仅地形变化时重绘），水面逐帧动画；实体绘制为像素贴图 blit。
