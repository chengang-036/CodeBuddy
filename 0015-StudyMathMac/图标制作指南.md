# 应用图标制作指南

## 🎨 快速方案：使用在线生成工具

### 方案A：AppIcon.co（推荐）

1. **访问网站**：https://www.appicon.co/
2. **上传图片**：拖拽一张至少 1024x1024 的图片
3. **选择平台**：勾选 macOS
4. **下载**：点击 Generate，下载 AppIcon.zip
5. **解压**：得到 `AppIcon.appiconset` 文件夹

### 方案B：使用预设图片

访问这些免费图标网站：
- **SF Symbols**：Mac 自带，打开"SF Symbols"应用
- **IconFinder**：https://www.iconfinder.com/
- **Flaticon**：https://www.flaticon.com/
- **Noun Project**：https://thenounproject.com/

搜索关键词：
- `math` (数学)
- `notebook` (笔记本)
- `education` (教育)
- `study` (学习)
- `calculator` (计算器)

## 📋 在 Xcode 中添加图标

### 步骤1：打开 Assets

1. 在 Xcode 左侧项目导航器中
2. 点击 **Assets.xcassets**
3. 点击 **AppIcon**

### 步骤2：添加图标文件

**方法A - 直接拖拽文件夹**（推荐）：
1. 如果你下载了 `AppIcon.appiconset`
2. 删除 Xcode 中现有的 AppIcon
3. 将整个 `.appiconset` 文件夹拖入 Assets.xcassets

**方法B - 逐个添加**：
1. 准备以下尺寸的图标：
   - 16x16 (1x 和 2x)
   - 32x32 (1x 和 2x)
   - 128x128 (1x 和 2x)
   - 256x256 (1x 和 2x)
   - 512x512 (1x 和 2x)
2. 将对应尺寸的图片拖到对应位置

### 步骤3：验证

1. 运行应用 (⌘R)
2. 检查 Dock 中的应用图标
3. 检查应用程序文件夹中的图标

## 🎨 临时方案：使用 emoji 或文字图标

如果暂时没有设计好的图标，可以用这个简易方法：

### 使用系统预览制作简单图标

1. 打开"预览"应用
2. **文件** → **新建** → 选择大小 1024x1024
3. 使用工具绘制：
   - 选择形状工具画圆形或方形背景
   - 选择文字工具输入 "数学" 或 "📐"
   - 调整颜色和大小
4. **文件** → **导出** → 保存为 PNG
5. 使用这个 PNG 通过上面的方案 A 生成完整图标集

## 🎯 推荐的图标设计

### 颜色建议
- **主色**：蓝色 `#4A90E2`（学习、理性）
- **辅助色**：橙色 `#FF9500`（活力、错题）
- **背景**：白色或渐变

### 图案建议
1. **数学符号**：∫ π √ Σ ∞
2. **几何图形**：三角形、圆形、函数曲线
3. **学习元素**：笔记本、铅笔、橡皮擦
4. **组合图案**：笔记本+数学符号

### 设计原则
- ✅ 简洁明了
- ✅ 辨识度高
- ✅ 圆角矩形背景
- ✅ 避免过多细节
- ✅ 在小尺寸下依然清晰

## 🚀 快速测试图标

创建图标后，在 Xcode 中：

1. **清理构建**：⌘⇧K
2. **重新构建**：⌘B
3. **运行应用**：⌘R
4. 查看 Dock 中的图标效果

如果图标没有更新：
- 退出应用
- 在 Xcode 中 **Product** → **Clean Build Folder**
- 重新运行

## 📦 导出应用时的图标

当你使用 **Archive** → **Copy App** 导出应用时，图标会自动包含在内。

用户在其他 Mac 上看到的图标就是你配置的这个图标。
