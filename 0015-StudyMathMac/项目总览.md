# 高中数学错题本 Mac应用 - 项目总览

## 🎯 项目简介

这是一个使用SwiftUI开发的原生Mac应用，旨在帮助高中生管理和分析数学错题，提高学习效率。

## 📦 项目内容

### 核心代码文件（18个Swift文件）

#### 应用入口
- `StudyMathMacApp.swift` - 应用主入口，配置窗口和菜单
- `ContentView.swift` - 主视图，三栏布局

#### 数据模型（Models/）
- `ErrorRecord.swift` - 错题记录模型（CoreData）
- `Methodology.swift` - 学习方法论模型（CoreData）
- `PersistenceController.swift` - CoreData持久化控制器

#### 视图模型（ViewModels/）
- `ErrorViewModel.swift` - 错题业务逻辑
- `MethodologyViewModel.swift` - 方法论业务逻辑

#### 视图组件（Views/Components/）
- `SidebarView.swift` - 左侧导航栏
- `ErrorListView.swift` - 中间错题列表
- `ErrorDetailView.swift` - 右侧错题详情
- `ErrorEditView.swift` - 错题编辑表单
- `MethodologyListView.swift` - 方法论管理
- `SettingsView.swift` - 应用设置

#### 服务层（Services/）
- `ImageManager.swift` - 图片本地存储管理
- `DouBaoService.swift` - 豆包AI识别服务

### 配置文件

- `Info.plist` - 应用配置
- `.gitignore` - Git忽略规则
- `StudyMath.xcdatamodeld/` - CoreData数据模型

```
│  - SidebarView                      │

│  - ErrorEditView                    │
└─────────────┬───────────────────────┘
              │
              │ Binding
              ↓
┌─────────────────────────────────────┐
│      ViewModels (ObservableObject)  │
│  - ErrorViewModel                   │
│  - MethodologyViewModel             │
└─────────────┬───────────────────────┘
              │
              │ CRUD Operations
              ↓
┌─────────────────────────────────────┐
│        Models (CoreData)            │
│  - ErrorRecord                      │
│  - Methodology                      │

└─────────────────────────────────────┘

┌─────────────────────────────────────┐

│  - ImageManager (图片存储)          │
```


## 🚀 主要功能

### 1. 错题管理
- ✅ 新增/编辑/删除错题
- ✅ 多图片上传（选择/拖拽/粘贴）
- ✅ 按难度筛选（基础/中等/难题）
- ✅ 按掌握程度筛选（未掌握/基本掌握/已掌握）
- ✅ 全文搜索

### 2. AI识别
- ✅ 调用豆包API识别题目图片
- ✅ 自动提取文字内容
- ✅ 支持批量识别

### 3. 方法论管理
- ✅ 记录解题方法
- ✅ 分类管理（解题方法/思维方式/学习技巧/知识总结）
- ✅ 示例存储

### 4. 数据存储
- ✅ CoreData本地存储
- ✅ 图片文件系统存储
- ✅ UserDefaults配置存储

### 5. 统计分析
- ✅ 总题数统计
- ✅ 未掌握题数
- ✅ 薄弱章节识别

## 📊 数据流

```
用户操作
   ↓
SwiftUI View
   ↓
ViewModel (ObservableObject)
   ↓
Model (CoreData Entity)
   ↓
PersistenceController
   ↓
SQLite数据库

图片数据流：
用户选择图片
   ↓
ErrorEditView
   ↓
ImageManager
   ↓
文件系统 (~/Library/Application Support/StudyMathMac/Images/)
```

## 🎨 技术亮点

1. **SwiftUI声明式UI** - 代码简洁，易维护
2. **CoreData集成** - 强大的数据持久化
3. **MVVM架构** - 清晰的职责分离
4. **Combine响应式编程** - 流畅的数据流
5. **原生Mac体验** - 三栏布局、快捷键、原生控件

## 📖 使用场景

### 场景1：课后错题整理
1. 拍摄错题照片
2. 粘贴到应用（⌘⇧V）
3. 点击AI识别自动提取文字
4. 填写错误原因和反思
5. 保存

### 场景2：考前复习
1. 筛选"未掌握"的题目
2. 逐个查看详情
3. 标记掌握程度变化
4. 重点复习薄弱章节

### 场景3：方法总结
1. 发现好的解题方法
2. 添加到方法论（⌘M）
3. 记录思路和技巧
4. 后续遇到类似题目可查阅
