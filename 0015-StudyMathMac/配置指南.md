# Mac应用配置指南

## 开发环境设置

### 1. Xcode项目创建

由于我无法直接创建Xcode项目文件，你需要手动创建：

1. 打开Xcode
2. 选择 **File → New → Project**
3. 选择 **macOS → App**
4. 填写项目信息：
   - Product Name: `StudyMathMac`
   - Interface: **SwiftUI**
   - Language: **Swift**
   - Storage: **Core Data** ✅
   - Location: `/Users/tiger/Documents/1-ChenGang/17-CodeBuddy/0015-StudyMathMac/`

### 2. 项目配置

#### 最低系统版本
- 在项目设置中，将 **Deployment Target** 设置为 **macOS 13.0** 或更高

#### 沙盒权限（如需App Store发布）
在 **Signing & Capabilities** 中添加：
- ✅ File Access (User Selected File: Read/Write)
- ✅ Network (Outgoing Connections)

### 3. CoreData模型配置

在Xcode中打开 `StudyMath.xcdatamodeld`，创建以下实体：

#### Entity: ErrorRecord
| 属性 | 类型 | Optional | 默认值 |
|------|------|----------|--------|
| id | UUID | No | - |
| date | Date | No | - |
| chapter | String | No | "" |
| difficulty | String | No | "" |
| mastery | String | No | "" |
| questionDescription | String | No | "" |
| errorReason | String | No | "" |
| correctSolution | String | No | "" |
| imagePaths | Transformable (Array) | No | [] |
| createdAt | Date | No | - |
| updatedAt | Date | No | - |

#### Entity: Methodology
| 属性 | 类型 | Optional | 默认值 |
|------|------|----------|--------|
| id | UUID | No | - |
| title | String | No | "" |
| content | String | No | "" |
| createdAt | Date | No | - |
| updatedAt | Date | No | - |

### 5. 豆包API配置

在 `Services/DouBaoService.swift` 中配置：

```swift
struct Config {
    static var apiKey = "your-api-key-here"
    static var endpointId = "your-endpoint-id-here"
    static let endpoint = "https://ark.cn-beijing.volces.com/api/v3/chat/completions"
}
```

或者在应用中创建设置界面让用户输入。
