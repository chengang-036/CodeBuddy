# 快速开始指南

这个指南将帮助你在10分钟内运行起来这个Mac应用。

## 📝 前置准备

1. ✅ Mac电脑（macOS 13.0+）
2. ✅ Xcode 15.0+（从App Store免费下载）
3. ✅ 豆包API账号（可选，用于AI识别）

## 🚀 五步运行

### 步骤1：打开Xcode（2分钟）

1. 打开Xcode应用
2. 点击 **File** > **New** > **Project...**
3. 选择 **macOS** 标签
4. 选择 **App** 模板，点击 **Next**

### 步骤2：配置项目（1分钟）

填写项目信息：
- **Product Name**: `StudyMathMac`
- **Team**: None（或你的开发团队）
- **Organization Identifier**: `com.yourname`
- **Interface**: SwiftUI
- **Language**: Swift
- **Storage**: ✅ 勾选 **Use Core Data**

点击 **Next**，选择 `0015-StudyMathMac` 目录保存，点击 **Create**

### 步骤3：导入源代码（3分钟）

在Finder中打开项目目录，将以下文件夹拖入Xcode项目：

1. 拖入 `Models` 文件夹
2. 拖入 `ViewModels` 文件夹
3. 拖入 `Services` 文件夹
4. 拖入 `Views` 文件夹
5. 拖入 `StudyMathMacApp.swift` 和 `ContentView.swift`
6. 拖入 `StudyMath.xcdatamodeld` 文件夹

**重要**：在弹出对话框中确保勾选：
- ✅ **Copy items if needed**
- ✅ **Create groups**
- ✅ **Add to targets**: StudyMathMac

### 步骤4：删除默认文件（30秒）

Xcode会自动生成一些文件，需要删除：
1. 右键点击 `StudyMathMac.xcdatamodeld`（Xcode生成的）
2. 选择 **Delete** > **Move to Trash**
3. 同样删除默认的 `ContentView.swift` 和 `StudyMathMacApp.swift`

（因为我们已经导入了自己的版本）

### 步骤5：运行应用（30秒）

1. 在Xcode顶部选择运行目标为 **My Mac**
2. 点击运行按钮（▶️）或按 **⌘R**
3. 应用启动成功！🎉

## ⚙️ 首次配置

### 配置豆包API（可选）

如果你想使用AI识别功能：

1. 在应用中按 **⌘,** 打开设置
2. 在"AI设置"标签中填入：
   - API Key: `your-api-key`
   - Endpoint ID: `ep-xxxxx`

详细配置步骤见 [配置指南.md](./配置指南.md)

### 不使用AI识别

如果暂时不用AI识别功能，可以跳过上面的配置，直接：
- 手动录入题目信息
- 粘贴或选择图片
- 填写题目描述、错误原因等

## 🎯 快速上手

### 添加第一个错题

1. 点击右上角 **+** 按钮（或按 **⌘N**）
2. 填写章节：如"二次函数"
3. 选择难度和掌握程度
4. 点击"选择图片"添加题目照片
5. （可选）点击"AI识别"自动提取文字
6. 填写错误原因和正确解法
7. 点击"保存"

### 查看错题列表

- 左侧边栏选择分类（全部/基础/中等/难题）
- 中间列表显示所有符合条件的错题
- 点击任意错题，右侧显示详情

### 搜索错题

- 使用顶部搜索框
- 输入章节名、题目描述等关键词
- 列表实时筛选

### 添加学习方法论

1. 按 **⌘M** 打开方法论管理
2. 点击 **+** 添加新方法论
3. 填写标题、分类、内容和示例
4. 保存

## 🔧 常见问题

### Q1: 构建失败，提示找不到某个文件

**A**: 确保所有文件都已正确添加到项目Target中。
- 选中文件
- 查看右侧"File Inspector"
- 勾选"Target Membership"中的 StudyMathMac

### Q2: 运行时崩溃

**A**: 可能是Core Data模型问题。
- 确保使用了我们的 `StudyMath.xcdatamodeld` 而不是Xcode自动生成的
- 删除自动生成的模型文件

### Q3: 图片无法保存

**A**: 需要配置App Sandbox权限。
1. 选择项目 > Target > Signing & Capabilities
2. 添加 App Sandbox capability
3. 勾选 "User Selected File: Read/Write"

### Q4: AI识别不工作

**A**: 
- 检查网络连接
- 确认API Key和Endpoint ID填写正确
- 查看Xcode控制台的错误信息
